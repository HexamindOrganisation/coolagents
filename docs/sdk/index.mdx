## Building agents

| Symbol | What it does |
|---|---|
| `create_agent(model, tools, system_prompt, …)` | Build a native agent + handler. See [Build an agent](/guides/build-an-agent). |
| `agent_tool(name=…)` | Decorator that turns an async function into a policy-gated tool. |
| `create_manifest(agent, …)` | Derive an `AgentManifest` from any supported agent without POSTing it. See [register](/cli/register). |
| `AgentManifest` | Pydantic model the platform stores and the dashboard renders. |

## Policy enforcement

| Symbol | What it does |
|---|---|
| `enforce_policy(agent, policy, approval_handler=…)` | Apply a `AgentPolicy` or YAML path to an agent. Accepts an optional handler for `approval_required` outcomes. See [policy YAML shape](/policy/yaml-shape). |

## Running agents

| Symbol | What it does |
|---|---|
| `stream_agent(agent, handler, message)` | Yield normalized events (text deltas, tool lifecycle, run end). See [Build an agent](/guides/build-an-agent#stream-results). |
| `stream_agent_raw(...)` | Lower-level streaming without normalization. |
| `invoke_agent(...)` | Run to completion and return the final result. |

## Loading agents

| Symbol | What it does |
|---|---|
| `load_agent(name)` | Resolve by name — platform when `HEXGATE_API_KEY` is set, else local/registered/builtin. |
| `load_hexgate_agent(name)` | Fetch a named agent (+ roles) from the platform. See [user scope](/concepts/user-scope). |
| `load_builtin_agent(name)` / `list_builtin_agents()` | Official starter agents shipped in `hexgate.builtin_agents`. |
| `register_agent(...)` | Register a code-defined agent so `load_agent` can resolve it. |

## Identity & built-in tools

| Symbol | What it does |
|---|---|
| `User(user_id, role=…, session_id=…, ttl_seconds=…)` | Per-request scope context manager. See [user scope](/concepts/user-scope). |
| `web_search` | Built-in search tool (needs `LINKUP_API_KEY`). |
| `fetch` | Built-in URL fetch tool (needs `TAVILY_API_KEY`). |

Filesystem tools (`read_file`, `write_file`, `edit_file`, `glob`, `grep`, `bash`)
are also importable from `hexgate`; the shell-backed ones run inside the
[workspace sandbox](/concepts/sandbox).
